# EnerVision AI

## AI Powered Smart Energy Audit and Sustainability Platform for MSMEs

EnerVision AI is an AI-based smart energy auditing platform developed for the Maverick Challenge 2026. It helps MSMEs predict energy consumption, estimate electricity cost, monitor equipment health, reduce energy wastage, and improve sustainability using Artificial Intelligence.

## Features

- Energy Consumption Prediction
- Electricity Cost Estimation
- Equipment Health Analysis
- Sustainability Score
- AI Recommendations
- Automatic PDF Report Generation
- Interactive Dashboard

  ## Technology Stack

- Python
- Streamlit
- Machine Learning (Random Forest)
- Pandas
- Scikit-learn
- Joblib
- ReportLab

  ## Project Workflow

1. Input Factory Parameters
2. Predict Energy Consumption
3. Estimate Electricity Cost
4. Analyze Equipment Health
5. Calculate Sustainability Score
6. Generate AI Recommendations
7. Create PDF Energy Audit Report
